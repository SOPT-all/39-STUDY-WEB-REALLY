## 소개

React 공식문서 '상호작용성 더하기' 중 이어지는 3개 문서를 정리했습니다.
같은 state를 여러 번 업데이트할 때 React가 업데이트를 모아서 처리하는 방식(배칭)과 업데이터 함수, state에 든 객체를 직접 고치지 않고 새 객체로 교체해야 하는 이유와 전개 문법,중첩 객체,Immer, 배열 state를 추가,제거,변환,교체,삽입,정렬하는 방법과 배열 안의 객체를 업데이트하는 방법까지 다뤘고, 각 문서의 챌린지를 1문제씩 풀었습니다.
