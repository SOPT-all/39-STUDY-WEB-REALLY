## 소개

React 공식문서 'UI 표현하기' 중 나머지 4개 문서를 정리했습니다.
조건에 따라 다르게 보여주는 방법부터 배열을 리스트로 그리는 방법과 key의 역할, 컴포넌트를 순수하게 유지해야 하는 이유, React가 UI를 트리로 다루는 방식까지 다뤘고, 각 문서의 챌린지를 1문제씩 풀었습니다. (트리로서의 UI는 챌린지 없음)
